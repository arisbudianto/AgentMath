# M09 — Operasional dan audit AI

Guru pemilik asesmen membuka **Asesmen → Operasional dan audit AI**. Halaman proses M05 juga menautkan audit yang difilter untuk proses tersebut. Membuka laporan atau CSV tidak memanggil AI.

## Cakupan pencatatan

Sejak M09 dipasang, setiap permintaan melalui alur aplikasi dicatat sebelum menghubungi provider: A1/A2 rubrik, transkripsi foto, Marker/Arbitrator/Confidence M05 dan baseline M08. Preflight, arbitrase yang dilewati, cache/replay UUID tanpa permintaan baru, dan pemeriksaan konfigurasi yang menolak sebelum HTTP tidak menambah panggilan audit. Retry yang benar-benar mengirim HTTP menghasilkan baris baru.

Tabel `ai_calls` menyimpan ID asesmen/sumber/korelasi, tahap, provider/model yang diminta, versi prompt, waktu mulai/selesai, durasi HTTP dalam ms, status HTTP, token input/output/cache yang valid dan tarif/estimasi opsional. Tidak menyimpan isi jawaban/foto, prompt lengkap, respons mentah, header, pesan exception provider, nama/kode peserta, atau API key. Link sumber membuka riwayat privat yang sudah tersedia.

`response_received` hanya berarti respons HTTP diterima, termasuk HTTP gagal. `transport_failed` berarti tidak ada respons yang dapat dicatat. `validated` berarti keluaran tahap lolos validator; ini bukan persetujuan guru atau jaminan hasil akhirnya dipakai. `rejected` mencakup kegagalan HTTP, format atau validasi operasi AI terkait. A1/A2 berbagi hasil validasi operasi pembuatan rubrik; bila A2 gagal, kedua panggilan tetap tercatat dengan outcome rejected. Perubahan sumber sesudah AI selesai atau pembatalan dapat membuang hasil; status akhir harus dilihat pada proses sumber.

Worker yang dihentikan paksa dapat meninggalkan `in_flight`/`pending`. Catatan ini ditampilkan sebagai belum diketahui, tanpa skor atau estimasi token/biaya buatan. Riwayat sebelum M09 tidak di-backfill karena biaya panggilan gagal/metadata yang hilang tidak dapat dibuktikan. Histori modul sebelumnya tetap tersedia.

Audit tersimpan terpisah dari transaksi penyimpanan hasil normal sehingga kegagalan validasi/draf tidak menghilangkan metadata panggilan. Operasi domain memasang scope audit `AiAudit::within(...)`; adapter memakai `AiAudit::request(...)`. Pemanggil internal baru wajib memakai scope tersebut. Direct adapter tests tanpa scope tidak membuat rekaman tanpa pemilik. Bila penyimpanan rekaman awal gagal, HTTP tidak dikirim. Gangguan database setelah HTTP dapat meninggalkan audit belum lengkap; audit ini tidak menggantikan rekonsiliasi provider. Satu transaksi luar yang sengaja di-rollback, seperti smoke test, turut me-rollback ledger.

## Estimasi biaya

Tidak ada asumsi tarif Dinoiki/OpenAI atau mata uang. Operator mengisi konfigurasi environment server berikut berdasarkan tarif akun yang telah diverifikasi, kemudian membangun ulang cache konfigurasi dan mengembalikan mode cache ke 600 di bawah OS worker lock:

```dotenv
AI_PRICE_PROVIDER=dinoiki
AI_PRICE_MODEL=gpt-5-mini
AI_PRICE_CURRENCY=
AI_PRICE_VERSION=
AI_PRICE_INPUT_PER_MILLION=
AI_PRICE_CACHED_PER_MILLION=
AI_PRICE_OUTPUT_PER_MILLION=
```

Mata uang: tiga huruf kapital (misalnya USD atau IDR). Versi tarif: 1–80 huruf/angka/titik/garis bawah/tanda minus, misalnya tanggal berlakunya. Harga merupakan unit mata uang per **satu juta token**, 0–10000, maksimal enam desimal. Semua kolom harus valid dan provider/model harus cocok persis agar tarif dipakai. Biarkan kosong bila tarif belum diketahui; harga contoh tidak disertakan agar tidak dianggap tarif nyata. Konfigurasi ini tidak mengaktifkan AI atau mengubah provider/model/key.

Tarif disalin ke rekaman sebelum request; perubahan harga tidak menghitung ulang riwayat. Rumus estimasi:

`((input − cached) × harga_input + cached × harga_cache + output × harga_output) / 1.000.000`

Token harus bilangan bulat nonnegatif, maksimal satu miliar. Cache harus tidak melebihi input. Bila cache tidak diketahui dan harganya berbeda dari input biasa, estimasi tidak dihitung. Jika harga cache sama dengan input, jumlah input total sudah cukup. Nol merupakan biaya valid hanya bila tarif dan token yang dibutuhkan diketahui; null berarti belum dapat dihitung. Perhitungan estimasi dibulatkan hingga 12 desimal, bukan aritmetika tagihan akuntansi.

Metadata usage pada respons ditolak tetap dicatat bila valid. Hal ini belum membuktikan provider menagih permintaan tersebut. Kredit, pajak, konversi kurs, biaya non-token, cache write atau diskon khusus tidak dimodelkan. Tidak tersedia budget cap, penagihan/pembayaran, pembelian kredit, atau retry otomatis baru.

## Laporan dan akses

Filter tanggal UTC (default 30 hari, maksimum 93 hari), jenis operasi, outcome dan ID proses M05. Ringkasan mencakup seluruh hasil filter, sementara halaman menampilkan 25 panggilan. Total token diberi keterangan dapat parsial beserta jumlah panggilan bermetadata lengkap; kosong bukan nol. Estimasi dikelompokkan per mata uang dan hanya menjumlahkan baris yang dapat dihitung. Filter proses M05 mencakup seluruh attempt, termasuk retry gagal yang tercatat.

CSV memakai filter yang sama, batas 10.000 baris dan batas ID tertinggi saat ekspor dimulai. Tersedia token, waktu, status, versi model/prompt, korelasi dan snapshot tarif. Formula dinetralisasi, UTF-8 BOM, private/no-store/nosniff. HTML juga no-store. Guru lain, admin dan siswa tidak memperoleh akses asesmen pemilik. Tidak ada publikasi nilai atau perubahan keputusan M06.

Migrasi menambah satu tabel; tidak mengubah jawaban, histori penilaian, acuan atau akun. Rekaman terminal tidak dapat diedit/dihapus lewat model. Pencatatan ini adalah audit operasional aplikasi, bukan log anti-tamper untuk administrator database.
