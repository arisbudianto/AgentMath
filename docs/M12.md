# M12 — Kualitas acuan penelitian

M12 menambahkan protokol opsional dua penilai manusia dan adjudikasi, serta evaluasi transkripsi foto. Dataset lama dan acuan tunggal tetap dapat digunakan; kebijakan baru dipilih ketika membuat dataset.

## Alur

1. Daftarkan protokol dan kasus tuning/test seperti M08. Pilih kewajiban dua penilai bila diperlukan.
2. Kumpulkan label A/B secara independen di luar aplikasi menggunakan kode samaran berbeda. Form masing-masing menyembunyikan skor penilai lain dan keluaran penilaian AI. Pemilik dataset mencatat label dan menyatakan independensinya; aplikasi tidak membuktikan identitas, dua orang nyata, atau pembutaan di luar aplikasi.
3. Adjudikasi secara manual berdasarkan dua versi label terkini. Hasilnya menjadi versi acuan akhir; perubahan label memerlukan adjudikasi baru. Tidak ada penggabungan skor otomatis.
4. Untuk foto, masukkan transkripsi acuan dari gambar asli tanpa melihat transkripsi AI/guru. Foto tidak terbaca dibiarkan tanpa label, bukan ditebak.
5. Bekukan dataset. Protokol ketat menolak kasus tanpa pasangan dan adjudikasi. Manifest mengunci ID, versi dan checksum anotasi/acuan. Dataset beku tidak dapat diedit; buat dataset baru untuk koreksi.
6. Buka kualitas acuan atau CSV privat. Baseline tetap hanya menerima sumber soal, rubrik, dan jawaban; label manusia tidak dikirim ke AI.

## Metrik

Pasangan manusia: kecocokan total, MAE poin, MAE dinormalisasi maksimum kasus, dan kecocokan per kriteria. Total sama tidak menghapus perbedaan kriteria. Angka ini mengukur kesepakatan dua label, bukan akurasi populasi atau reliabilitas universal.

Foto: CER draf AI terakhir sebelum transkripsi terkonfirmasi dibandingkan dengan acuan manusia, terpisah dari CER teks sesudah konfirmasi guru. Tidak ada pemanggilan OCR ulang atau pengisian draf AI yang hilang. ID revisi/transkripsi, versi acuan, serta metadata provider/model/prompt yang tersedia disertakan pada ekspor; isi teks, kode penilai, alasan dan kredensial tidak diekspor.

CER = jarak edit karakter Unicode / jumlah karakter acuan × 100. Agregat memakai jumlah edit dibagi jumlah karakter acuan. Hanya akhir baris CRLF/CR dinormalisasi; spasi, huruf besar dan notasi matematika dipertahankan. CER dapat melebihi 100%; ini kesalahan teks, bukan kesalahan makna matematika. Definisi: [Hugging Face Evaluate CER](https://huggingface.co/spaces/evaluate-metric/cer/blob/main/README.md).

Perbandingan dibatasi 2.000 karakter per sisi dan 250.000 pasangan karakter. Sumber hilang, pembatasan dan kasus checksum tidak valid dilaporkan terpisah dan tidak dianggap nol kesalahan. Cakupan foto berlabel ditampilkan. Tidak ada interval kepercayaan/kappa otomatis; penelitian masih memerlukan sampel representatif, penilai nyata, target praregistrasi dan analisis yang sesuai desain.

## Integritas dan akses

Anotasi append-only, UUID replay, versi optimistis dan penguncian dataset/asesmen menjaga konsistensi. Pembuatan acuan akhir dan receipt adjudikasi atomik. Pemilik guru saja dapat mengakses; admin tidak melewati kepemilikan, siswa tidak mendapat akses. CSV dibatasi, formula dinetralkan dan no-store. Tidak ada AI call untuk anotasi atau pelaporan. M10/M11 dan keputusan nilai operasional tetap terpisah.

## Verifikasi lokal

157 tes / 1.488 assertions lulus: protokol ketat/legacy, pasangan berbeda, adjudikasi basi, replay, rollback, checksum, isolasi baseline, privasi peran/CSV/form, CER Unicode, spasi literal, draf hilang dan batas perhitungan. Seluruh data tes sintetis; bukan bukti akurasi empiris.
