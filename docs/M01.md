# M01 — Kelas dan paket asesmen

## Cakupan

Pengajar membuat dan menyunting kelas SD (jenjang 1–6, tahun ajaran/semester), peserta berkode, asesmen, soal, kunci jawaban, pedoman penilaian per soal, dan skor maksimum. Kode peserta dinormalisasi menjadi kapital serta unik per kelas. Tidak ada kolom identitas langsung siswa.

Nomor soal unik per asesmen. Skor maksimum lebih dari 0, paling besar 10.000, dan paling banyak dua angka desimal. Teks soal, kunci, dan pedoman wajib diisi, masing-masing maksimal 20.000 karakter. Petunjuk umum asesmen opsional. Belum ada penghapusan kelas/peserta/soal agar data tidak hilang tanpa alur revisi.

Paket dinyatakan lengkap saat memiliki kelas milik pengajar yang sama, minimal satu peserta, dan minimal satu soal yang lengkap. Status dihitung ulang dari data terkini; ini bukan pengesahan rubrik atau hasil penilaian AI. Asesmen lama M00 tetap tersimpan sebagai draf tanpa kelas dan dapat dilengkapi.

## Akses

Admin tidak mendapat akses kelas atau isi asesmen. Pengajar hanya mengelola data miliknya. Pilihan kelas di server dibatasi menurut pemilik; owner_id, classroom_id peserta, dan assessment_id soal tidak dapat dialihkan melalui formulir. Identitas anak pada URL dicari melalui relasi induknya, termasuk saat pengajar memiliki lebih dari satu asesmen.

## Kriteria penerimaan dan pengujian

- Alur kelas → peserta → asesmen → soal menghasilkan status Paket lengkap dan total skor yang benar.
- Perubahan kelas/peserta/soal tersimpan; draf tanpa kelas tetap didukung.
- Akses antarpengajar, admin, tamu, dan akun nonaktif ditolak.
- Duplikasi kode/nomor, skor di luar batas, jenjang non-SD, dan data wajib kosong ditolak.
- Isi formulir dirender dengan escaping Blade; teks matematika dapat memakai baris baru.
- Daftar kelas/asesmen/peserta memiliki pagination.

Tes: `vendor/bin/phpunit`; CI menjalankan seluruh pengujian pada PHP 8.3/8.4 dengan SQLite dan MariaDB. Pratinjau lokal telah menguji login pengajar dan pembuatan paket lengkap melalui browser dengan data sintetis. Upgrade SQLite M00→M01 diuji terpisah agar akun/asesmen lama dan owner_id tetap tersimpan.

## Deployment

Urutan: pengujian lokal → commit/push GitHub → CI berhasil untuk SHA yang sama → backup kode/database → preview SQL migrasi → deployment cPanel → migrate --force → config/view cache → smoke.

Migrasi M01 menambah classrooms, participants, questions serta dua kolom nullable pada assessments. Tidak ada penghapusan tabel/kolom dalam up(). Konfigurasi .env, APP_KEY, storage dan konfigurasi PHP web yang telah terpasang harus dipertahankan.

Rollback kode ke M00 dapat dilakukan tanpa menghapus tabel M01. Jangan migrate:rollback pada produksi karena down() menghapus data M01. Simpan backup sebelum migrasi dan evaluasi pemulihan database secara terpisah.
